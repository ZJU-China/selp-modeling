01

Build an Extended Protein Conformation in UCSF Chimera

Purpose
Build an extended starting conformation from the amino acid sequence.
Command
TerminalShell
chimera --nogui --script build_extended_peptide.py
Configuration

339 residues in chain A · backbone φ = −180° and ψ = 180°.

build_extended_peptide.pyPythonDownload file
from BuildStructure import placePeptide
import chimera


TAG = "KLGYIEFYKVEK"
LINKER = "GGGGSGGGGSGGGGS"
SELP_2KY5 = (
    "GKGVPGVGVPGVGVPGVGVPGYGVPGVGVPGVGVPGVGVPGRGDSGAGAGSGAGAGS"
    "GKGVPGVGVPGVGVPGVGVPGYGVPGVGVPGVGVPGVGVPGRGDSGAGAGSGAGAGS"
    "GKGVPGVGVPGVGVPGVGVPGYGVPGVGVPGVGVPGVGVPGRGDSGAGAGSGAGAGS"
    "GKGVPGVGVPGVGVPGVGVPGYGVPGVGVPGVGVPGVGVPGRGDSGAGAGSGAGAGS"
    "GKGVPGVGVPGVGVPGVGVPGYGVPGVGVPGVGVPGVGVPGRGDSGAGAGSGAGAGS"
)
SEQUENCE = TAG + LINKER + SELP_2KY5 + LINKER + TAG

if len(SELP_2KY5) != 285:
    raise ValueError("Unexpected 2KY5 length: %d" % len(SELP_2KY5))
if len(SEQUENCE) != 339:
    raise ValueError("Unexpected construct length: %d" % len(SEQUENCE))

phi_psis = [(-180.0, 180.0)] * len(SEQUENCE)
placePeptide(SEQUENCE, phi_psis, model="2KY5_snoopytag", chainID="A")
chimera.runCommand("write format pdb 0 2KY5_snoopytag.pdb")
print("BUILT_SEQUENCE_LENGTH %d" % len(SEQUENCE))
print("BUILT_SEQUENCE %s" % SEQUENCE)
chimera.runCommand("stop")

All-Atom Molecular Dynamics

Purpose
Sample monomer conformations and select a representative structure for coarse-graining.
Command
TerminalShell
bash run_preparation.sh
bash run_tiger2_100ns.sh
Configuration

NAMD 3.0.2 · CHARMM36m · hydrogen mass repartitioning · generalized Born implicit solvent (GBIS, ionic concentration 0.15 M) · 4 fs production time step. Minimize in vacuum and GBIS, then increase the time step from 0.25 to 4 fs.

tiger2_100ns_each.confNAMD / Tcl
# 1667 cycles x 60 ps = 100.02 ns per replica.
set num_replicas 4
set min_temp 280
set max_temp 400
set steps_equil1 500
set steps_sample 12000
set steps_equil2 2500
set num_runs 1667
set runs_per_frame 5
set frames_per_restart 5
set namd_config_file "tiger2_2ky5_snoopytag_base.namd"
set initial_coordinates "equil/07_gbis_eq_4fs.coor"
set output_root "production/%s/tiger2_2ky5_snoopytag"
source ./tiger2_protocol.namd

tiger2_100ns_each.conf · tiger2_protocol.namd · tiger2_2ky5_snoopytag_base.namd

Result

Four TIGER2 replicas (280–400 K) reached 100.02 ns each. The archived baseline-temperature Cα-RMSD medoid came from replica 2 at 64.74 ns.

Simulation Box Setup

Purpose
Pack 32 copies of the archived coarse-grained input and solvate the system and minimize its energy.
Command
TerminalShell
gmx insert-molecules -ci single_chain.gro -nmol 32 \
  -box 35.4569571362 33.0234609888 12.7604206119 \
  -radius 0.24 -scale 2 -try 1000 -seed 26100603 -o packed.gro
insane -f packed.gro -o raw.gro -p raw.top -pbc rectangular \
  -box 35.45696,33.02346,12.76042 -sol W -sold 0.46 -salt 0.15 -charge 224
gmx grompp -f em_bounded.mdp -c system.gro -p system.top -o em_bounded.tpr
gmx mdrun -s em_bounded.tpr -deffnm em_bounded
Configuration

Martini 3 · 579 beads per chain · target protein concentration ≈100 mg/mL. Initial NaCl setting: 0.15 mol/L. Steepest descent: up to 10,000 steps, initial step 0.001 nm, force tolerance 1,000 kJ mol⁻¹ nm⁻¹.
